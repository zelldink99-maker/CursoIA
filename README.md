# Proyecto de IA

Plantilla inicial para organizar un proyecto del curso y registrar su avance
desde el primer commit.

## Estructura

- `src/`: código fuente del proyecto.
- `docs/`: documentación y guía de trabajo.
- `tests/`: pruebas automatizadas.

## Inicio

Abre esta carpeta en Visual Studio Code y usa la terminal integrada para
trabajar con el proyecto. La guía de las etapas está en
[`docs/guia-de-trabajo.md`](docs/guia-de-trabajo.md).

La configuración del entorno de Python, las dependencias y las peticiones
autenticadas a una API se incorporarán en las etapas correspondientes del curso.
