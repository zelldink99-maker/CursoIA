# Guía de trabajo

## Objetivo

Preparar una base ordenada y reproducible para desarrollar el proyecto del
curso, manteniendo el código, la documentación y la configuración separados.

## Etapas

1. Crear la estructura base e iniciar el repositorio Git.
2. Registrar esta estructura con un primer commit.
3. En el siguiente bloque, crear y activar un entorno virtual e instalar las
   dependencias necesarias.
4. Más adelante, proteger las credenciales con variables de entorno y probar
   una petición autenticada a la API.

Las credenciales reales no deben guardarse en Git. El archivo `.env` está
excluido desde el inicio.
